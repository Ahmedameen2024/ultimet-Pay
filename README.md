# Ultimate Pay | ألتميت باي — حلول المدفوعات والتحصيل الذكي

منظومة المدفوعات ونقاط البيع الذكية والمحول المالي المعتمد في الجمهورية اليمنية.

## 🌟 مميزات المنظومة
- **تعدد القنوات (Omni-Channel)**: دعم أجهزة Soft POS اللاتلامسية (Tap-to-Phone)، أجهزة Android POS الذكية، رموز الاستجابة السريعة Dynamic QR، وروابط الدفع الفورية.
- **تكامل محاسبي مباشر**: ترحيل آلي للمبيعات مع نظام **Onyx ERP** لتسوية القيود والمطابقة الفورية دون إدخال يدوي.
- **مسارات مخصصة للجمهور (3 Audience Tracks)**:
  1. مسار التجار وأصحاب الأنشطة التجارية (Merchants).
  2. مسار البنوك والمؤسسات المالية (Merchant Acquiring).
  3. مسار محول الدفع ونقاط البيع المتقدمة (Payment Switch & POS).
- **محاكي دفع تفاعلي**: تجربة فورية لكافة سيناريوهات الدفع والتحصيل وطباعة الإيصالات.
- **دعم ثنائي اللغة (Bilingual)**: واجهة عربية متكاملة (RTL) وإنجليزية (LTR).
- **مظهر متكيف (Theme Switching)**: دعم الوضعين الليلي والنهاري.
- **كتيب الشرائح التفاعلي**: استعراض شرائح العرض التعريفي المعتمد للشركة بدقة عالية.
- **تكامل واتساب مباشر**: زر عائم وبطاقة اتصال سريعة للتواصل الفوري على الرقم المعتمد `782665485`.

## 🛠️ التقنيات المستخدمة
- HTML5 (دلالي ومتجاوب)
- Modern Vanilla CSS (Dark/Light Modes, Glassmorphism, Micro-animations)
- JavaScript (Vanilla ES6+)
- Font Awesome 6 Icons
- Google Fonts (Cairo & Outfit)

## 🚀 المعاينة والتشغيل
يمكن فتح الملف `index.html` مباشرة في أي متصفح ويب حديث دون الحاجة لتثبيت أي حزم خارجية.
